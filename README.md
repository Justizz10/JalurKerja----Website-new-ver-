# Jalurkerja — Landing Page Job Search

Jalurkerja adalah landing page pencarian kerja yang dirancang untuk membantu pencari kerja menemukan lowongan yang lebih relevan berdasarkan posisi, skill, lokasi, pengalaman, dan tipe pekerjaan.

Project ini dibuat sebagai bagian dari tugas pengembangan landing page menggunakan HTML dan CSS dengan pendekatan desain modern, sederhana, dan responsif.

## Preview

Jalurkerja menggunakan konsep visual dark mode dengan inspirasi desain modern seperti Linear, dengan fokus utama pada:

- Pencarian lowongan
- Daftar lowongan yang terstruktur
- Filter pengalaman dan tipe pekerjaan
- Kategori pekerjaan
- Informasi cara kerja
- Informasi manfaat platform
- Alur lamaran kerja sederhana

## Fitur

### 🔎 Pencarian Lowongan

Pengguna dapat mencari lowongan berdasarkan:

- Posisi
- Skill
- Kata kunci
- Lokasi

### 💼 Daftar Lowongan

Menampilkan beberapa contoh lowongan pekerjaan dengan informasi:

- Nama perusahaan
- Posisi
- Lokasi
- Tipe pekerjaan
- Pengalaman
- Perkiraan gaji
- Skill yang dibutuhkan

### 🗂️ Filter Lowongan

Tersedia filter berdasarkan:

- Pengalaman
  - Semua pengalaman
  - Fresh graduate
  - 1–3 tahun
  - 3–5 tahun
  - 5+ tahun

- Tipe pekerjaan
  - Semua tipe
  - Penuh waktu
  - Paruh waktu
  - Freelance

### 📁 Kategori Pekerjaan

Kategori yang tersedia:

- Semua
- IT
- Operations
- Design
- Content

### 📄 Detail Lowongan

Setiap lowongan memiliki halaman detail berbentuk modal yang menampilkan:

- Deskripsi pekerjaan
- Lokasi
- Jenis pekerjaan
- Gaji
- Persyaratan
- Tombol untuk melamar

### 📝 Alur Lamaran

Landing page juga menyediakan simulasi alur lamaran:

1. Membuka detail lowongan
2. Memilih "Lamar sekarang"
3. Mengisi nama lengkap
4. Mengunggah CV
5. Melakukan konfirmasi
6. Lamaran berhasil dikirim

## Teknologi

Project ini dibuat menggunakan:

- HTML5
- CSS3
- Google Fonts — Inter

Tidak menggunakan JavaScript.

Interaksi seperti modal dan alur lamaran memanfaatkan fitur HTML dan CSS seperti:

- Anchor link
- `:target`
- Form HTML
- Responsive CSS
- CSS animation
